# CineTrack — Movie Watchlist Management System

CineTrack is a Laravel MVC CRUD application created for the Module 4 practical activity. The enhanced version preserves the required MVC implementation while adding authentication, user roles, movie ownership, dashboard statistics, search/filtering, favorites, profile management, and a more organized responsive interface.

See `UPGRADE_NOTES.md` for setup instructions, demo accounts, and a summary of the enhancements.
